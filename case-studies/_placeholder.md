# Efficio Case Studies

This directory hosts customer case studies.

The canonical template lives in the internal ops workspace at
`Efficio/outputs/wave151_case_study_template.md`. The first paying
customer case study will replace this file with a real writeup at
`case-studies/<company-slug>.md`.

Structure each case study follows:

1. Company snapshot (industry, size, tools, pain)
2. 2. The build (week-by-week, X days from audit to live)
   3. 3. The result (hard numbers at Day 30)
      4. 4. Customer quote (2-4 sentences, signed off)
         5. 5. What we'd change (honest section)
